Hero Background Image

To complete the design, please add a high-resolution spiritual or Hindu-themed background image named hero-bg.jpg in this folder.

Good image options include:

  • A serene temple during sunrise or sunset
  • Om symbol with decorative elements
  • Ganges river with temples
  • Mandala or sacred geometry patterns
  • Peaceful meditation scene

Recommended image specifications:

Resolution: At least 1920×1080 pixels
Aspect ratio: 16:9
Format: JPG or WebP
File size: Optimized for web (less than 500KB if possible)

The image will be used as the background for the hero section with an overlay to ensure text remains readable.
