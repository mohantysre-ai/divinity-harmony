User Avatar Image

To complete the design, please add a user avatar image named avatar.jpg in this folder.

Good avatar options include:

  • A professional headshot
  • A simple profile picture
  • Or any appropriate user avatar

Recommended image specifications:

Resolution: At least 400×400 pixels
Aspect ratio: 1:1 (square)
Format: JPG, PNG or WebP
File size: Optimized for web (less than 200KB if possible)

The image will be used as the user avatar in the application.
